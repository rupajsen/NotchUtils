# Security

If you find a security problem in NotchUtils, please report it privately through GitHub's [private vulnerability reporting](https://github.com/rupajsen/NotchUtils/security/advisories/new) rather than opening a public issue.

The optional fan helper runs as root, so reports about it are especially welcome. Its source is in `Sources/NotchUtilsFanHelper` and `Sources/SMCKit`.

Only the latest release receives fixes.
